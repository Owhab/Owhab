GitHub profile README (github.com/Owhab). Kept aligned with the portfolio (owhab.com) and the current resume.

## Language

**Resume-Canonical**:
The rule that the current resume is the single source of truth for Experience, Skills, Education, and contact facts on this profile. The README may show richer content (agentic-engineering interests, speaking sessions, extra badges) but must never contradict the resume.
_Avoid_: Mirror, exact copy, resume clone
